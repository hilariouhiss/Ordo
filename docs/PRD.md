## 1. 产品概述

### 1.1 背景与目标

Ordo 是一款**本地优先（local-first）、单用户**的桌面应用，核心能力是**个人任务管理**与**项目管理**，次要能力是任务/项目**进度统计展示**。数据全部存储在本地，无需账号与网络即可完整使用。

### 1.2 目标用户

- 需要统一管理个人待办与多项目的知识工作者、开发者、学生。
- 偏好离线、数据自持、轻量快速桌面工具的用户。

### 1.3 产品定位

- **一句话**：一个现代、流畅、轻量的本地任务 + 项目桌面管理器。
- **核心价值**：快速捕获 → 清晰组织 → 直观看进度，全程离线、响应快、体积小。

### 1.4 技术基线

- 桌面框架：Tauri 2；前端：SolidJS + TypeScript + Tailwind CSS v4。
- 存储：SQLite（rusqlite + refinery 迁移）。
- 数据约定：UUID 主键、ISO-8601 UTC 时间戳、软删除（`deleted_at`）。
- 平台：Windows / macOS / Linux 三端。

## 2. 核心功能需求

### 2.1 任务管理（P0）

任务是本产品的最小管理单元。

**任务模型字段：**

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 标题 | 任务名 | 是 |
| 备注 | 富文本/纯文本描述 | 否 |
| 优先级 | 高 / 中 / 低 / 无 | 否（默认无） |
| 标签 | 多标签，多对多关联 | 否 |
| 截止时间 | 到期日期与时间 | 否 |
| 所属项目 | 可选，为空即「收件箱」任务 | 否 |
| 状态 | 待办 / 已完成（看板列见 2.2） | 是 |
| 完成时间 | 完成后自动记录 | 自动 |

**子任务：**

- 任务可包含多级子任务（至少支持一级，v1 可限制为一级）。
- 子任务具备独立完成状态与排序；父任务可展示子任务完成进度。
- 任务列表按层级展示子任务：父任务行可展开/收起，折叠时显示子任务完成进度（`已完成/总数`）。筛选与排序只作用于顶级任务——子任务没有优先级、标签与截止日期，把某个父任务的子任务筛掉会让进度数字与可见行数不一致。

**重复任务：**

- 支持每天 / 每周 / 每月 / 自定义间隔的重复规则。
- 完成后按规则生成下一次实例，重复规则可暂停/结束。

**截止与提醒：**

- 截止日期可设定为具体时间点。
- 到点触发桌面系统通知；支持提前提醒（如提前 10 分钟 / 1 小时）。

**标签与优先级：**

- 标签可自定义名称与颜色，任务可挂多个标签。
- 优先级四级，用于排序与筛选。

**时间记录（支撑统计，见 3.3）：**

- 任务上可登记耗时（手动录入，或「开始/停止」计时）。
- 时间记录与项目/标签关联，用于时间分布统计。

**任务视图（P0）：**

- 收件箱：未归属项目的任务。
- 今天：今日到期 + 今日需处理的任务。
- 即将到来：未来 7 天 / 自定义范围。
- 已完成：历史完成清单（支持软删除，可恢复）。
- 按优先级 / 标签 / 项目筛选与排序。

**搜索（P1）：**

- 基于 SQLite FTS5 对任务标题、备注、评论做全文搜索。

**验收要点：**

- 新建任务 < 1 秒内落库并可见；完成任务立即从「今天」视图消失并进入「已完成」。
- 重复任务完成后自动生成下一次，且可取消。
- 到期提醒在应用后台/托盘状态下仍可触发系统通知。

### 2.2 项目管理（P0）

项目是任务的容器与更高层级的组织单位。

**项目模型字段：** 名称、描述、颜色标识、图标、截止日期、状态（进行中 / 已归档）。

**三种项目视图：**

1. **列表视图（P0）**：项目内任务按优先级/截止日期/标签排序的清单，含完成率。
2. **看板视图（P0）**：多列看板（默认「待办 / 进行中 / 已完成」，支持自定义列），任务在列间**拖拽**切换状态、排序。
3. **进度视图（P1）**：项目总进度条、完成率、剩余任务量、距截止日剩余时间。

**项目级能力：**

- 项目内任务、子任务、时间记录均归属到项目（标签为全局，跨项目共享）。
- 项目归档（软删除，可恢复）。
- 项目内拖拽排序，顺序持久化。

**验收要点：**

- 看板拖拽流畅（拖拽过程不卡顿），松手后状态即时持久化。
- 项目进度随任务完成实时更新。

### 2.3 评论（P1）

- 任务可追加多条评论，用于记录上下文。
- 评论进入全文搜索范围。

## 3. 次要功能需求：统计展示

统计是**只读的洞察层**，不阻塞核心任务/项目流程。

### 3.1 完成趋势

- 每日 / 每周完成任务数曲线。
- 日历热力图（按日完成强度着色）。
- 支持按时间范围（近 7 天 / 30 天 / 本年）切换。

### 3.2 项目进度

- 各项目完成率、剩余任务量、里程碑/截止进度汇总。
- 项目间对比视图。

### 3.3 时间分布

- 按项目 / 标签聚合的时间花费与工作量分布。
- 支持日 / 周 / 月粒度。
- 数据来源为 2.1 中的时间记录。

**验收要点：**

- 统计数据在数据量达数千任务时仍能秒级生成；图表交互流畅。

## 4. 桌面端能力

| 能力 | 优先级 | 说明 |
| --- | --- | --- |
| 全局快捷键捕获 | P1 | 任意界面按下全局快捷键只弹出「快速添加任务」输入框（不唤起主界面），录入后消失，不影响当前工作 |
| 快捷输入标记 | P1 | 输入框内可用 `@项目` / `!高!中!低` / `#日期` 一次设好所属项目、优先级、截止日期；`#` 后接中文日期（明天、下周五、月底、周末、年底、明天下午3点）或数字写法（9/30、2026-09-30）。日期必须带 `#`，裸日期词只是普通文字，不会被误改标题；也可用输入框下方的控件设置，控件优先于标记 |
| 系统托盘常驻 | P1 | 关闭主窗口后驻留托盘；托盘菜单可快速唤起/退出 |
| 开机自启 | P2 | 可配置是否随系统登录启动（默认关闭） |
| 悬浮快速入口 | P2 | 桌面悬浮窗/小组件，快速查看今日任务与添加任务 |

**验收要点：**

- 全局快捷键在应用非前台（甚至无焦点）时可用。
- 托盘常驻下，提醒通知仍正常触发。

## 5. 非功能需求（NFR）

### 5.1 UI 现代

- 遵循统一设计系统（Tailwind v4 `@theme` 定义颜色/间距/圆角/字号/阴影 Token）。
- 使用 Kobalte 无样式原语自建组件，避免第三方 UI 库的「模板感」。
- **一套灰 + 一个强调色**：所有中性色同一色相、极低饱和；强调色用低饱和深青，与所有语义色（成功/警告/危险）保持足够色相距离，避免强调面被读成状态。
- **平面分层**：凹槽 / 页面 / 表面 / 浮起四层有明确的明度差，层级不靠描边表达；阴影用中性色相染过，不使用纯黑低透明度。
- **排版按桌面密度**：正文 13px、次要 12px、徽章 11px；数字统一等宽（`tabular-nums`）。
- 深色/浅色主题，跟随系统或手动切换。
- **字体内置系统字体栈**（`system-ui` 优先，CJK 按平台降级）。不打包 Web 字体：界面文字约 95% 是中文，引入拉丁展示字体会为署名和数字付出体积与字节，与 5.4 冲突。

### 5.2 运行流畅

- 主界面交互保持 60fps，长列表使用虚拟滚动。
- 数据读写走 Rust 后端命令，前端不阻塞主线程。

### 5.3 动效丝滑

- 动效仅使用 CSS `transform` / `opacity` / 独立的 `scale`、`translate` 属性等 GPU 友好属性。
- 微交互时长 150–300ms，采用自然缓动；不引入动画库。
- 遵循系统「减少动态效果」偏好（`prefers-reduced-motion`）；全局兜底规则在 `index.css`，组件不逐处重复声明。
- 所有可点元素都有 hover 与按下反馈（按下用 `scale` 收缩），所有浮层有入场动画；**不做退场动画**（Kobalte 会等动画结束才卸载元素，未触发的退场动画会留下一层吃掉点击的隐形遮罩）。
- 加载态用骨架屏而不是纯文字，骨架形状对齐最终布局，避免数据到达时跳版。

### 5.4 应用体积小

- 目标：Windows 安装包 < 30 MB（压缩后 < 15 MB），macOS / Linux 同量级。
- 复用已配置的 release 优化（LTO、strip、`opt-level=3`、`panic=abort`）。

### 5.5 响应快

- 冷启动（首屏可交互）< 1.5s，热启动 < 0.5s（目标值）。
- 任务/项目操作命令往返 < 50ms；统计查询秒级返回。

### 5.6 数据与隐私

- 所有数据仅存本地，不上传任何网络。
- v1 提供手动数据导出/备份能力（P1）；云同步为未来扩展，不在 v1 范围。

### 5.7 平台兼容

- Windows / macOS / Linux 三端一致体验；全局快捷键与托盘按平台适配。

## 6. 功能优先级与里程碑

### 6.1 MVP（首个可发布版本）

- 任务 CRUD + 子任务 + 优先级 + 标签 + 截止日期 + 提醒。
- 任务视图（收件箱 / 今天 / 即将到来 / 已完成）。
- 项目 CRUD + 列表视图 + 看板视图（拖拽）+ 进度。
- 本地持久化 + 全文搜索。

### 6.2 v1 完整版（MVP 之上）

- 重复任务、评论、时间记录。
- 统计仪表盘（完成趋势 / 项目进度 / 时间分布）。
- 全局快捷键捕获、系统托盘常驻、数据导出/备份。
- 深浅主题。

### 6.3 后续版本（P2 / 未来）

- 开机自启、悬浮快速入口。
- 云同步、多端（移动端）、番茄钟/专注计时、协作共享。

## 7. 数据模型概述（参考）

采用 `UUID 主键 + ISO-8601 时间戳 + 软删除` 约定，为未来同步/备份预留空间。核心实体：

- **Project**：项目。
- **Task**：任务（含 `project_id` 可空、`status` 映射看板列、`repeat_rule`、`due_at`、`completed_at`）。
- **Subtask**：子任务（关联 `task_id`）。
- **Tag / TaskTag**：标签及其与任务的多对多关系。
- **Comment**：任务评论。
- **TimeEntry**：时间记录（关联 `task_id`）。
- **Settings**：应用设置（键值）。

> 具体建表与迁移由实现阶段细化，遵循 `src-tauri/migrations/` 的 refinery 迁移流程。

## 8. 成功指标（目标值，非承诺）

- 冷启动 < 1.5s，热启动 < 0.5s。
- 安装包 < 30 MB。
- 核心操作命令往返 < 50ms；万级任务下统计秒级返回。
- 动效 60fps，无可见掉帧。

---

## 9. 范围外（Out of Scope，v1 不做）

- 账号体系、多用户、团队协作。
- 云同步（数据模型已预留，但不实现）。
- 移动端。
- 番茄钟 / 专注计时（时间记录已含，但无专注计时器）。
- 第三方日历/邮件等外部集成。
