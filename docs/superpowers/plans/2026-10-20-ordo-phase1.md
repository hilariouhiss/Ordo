# ordo Phase 1 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个可安装的 Windows 桌面应用：一句话捕获、每周过一遍、项目进度与时间轴、延期记录、归档、提醒、迷你窗口与 AI 补字段。

**Architecture:** Rust 拥有数据与调度（SQLite + 提醒线程），Vue 端按 MVVM 分 View / ViewModel / Model，全部跨进程调用经 `model/ipc.ts`。

**Tech Stack:** Tauri 2、Vue 3 + TypeScript、Vite+（`vp`）、Tailwind 4、daisyUI 5、SQLite（`rusqlite` bundled）、DeepSeek（OpenAI 兼容 HTTP）。

**Spec:** `docs/superpowers/specs/2026-10-19-ordo-design.md`（需求）与 `docs/superpowers/specs/2026-10-20-ordo-architecture.md`（架构）

## Global Constraints

- 平台：Windows 优先；Tauri 2；主入口 `src-tauri/src/lib.rs` 的 `run()`。
- 主键 UUID v4；日期 `YYYY-MM-DD`（本地日期）；时间戳 RFC3339 UTC；IPC 字段 camelCase。
- 界面不碰库、不碰 `invoke`；只有 ViewModel 调 `src/model/ipc.ts`。
- 所有写命令返回更新后的 DTO。
- 新依赖仅限：`rusqlite`(bundled)、`uuid`、`chrono`、`serde`、`serde_json`、`reqwest`(rustls)、`keyring`、`vue-router@4`、Tauri 插件 `notification` / `autostart` / `global-shortcut` / `single-instance` / `log`。
- 每个任务收尾必须：`cargo test`（在 `src-tauri`）通过、`vp test run` 通过、`vp check` 干净、提交一次。
- 文案：中文；日期显示沿用 `11/20` 形式；"我"是固定人员。
- TS 测试辅助（`task()`、`step()`、`defaultSettings`）统一放 `src/viewmodels/__tests__/fixtures.ts`。

## Review Focus

1. **空白与超长捕获**：只敲空格、或贴进两千字，不能产生空任务，也不能丢原句。—— Task 3 的测试覆盖。
2. **周界**：周一零点、跨年、机器时区变化时，"本周"与"过一遍"不能错位。—— Task 3、Task 5。
3. **提醒重复与错过**：重启、连续启动两次、应用关着错过一天，都不能重复弹，也不能漏掉。—— Task 12。
4. **AI 不可靠**：超时、空响应、返回不存在的项目/人员 ID、把日期写成"周五"。—— Task 14。
5. **快捷键与迷你窗口**：组合键被别的程序占用、窗口抢焦点、连按两次。—— Task 13。
