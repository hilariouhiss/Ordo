# ordo Phase 1.1 收口实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已经合并到 main 的 Phase 1 收到"可长期用、可发布"：通知点击能定位到任务、任务编辑不再整行覆盖、过一遍能就地拆开、托盘菜单齐全、生产 CSP 收紧、数据库坏了能恢复、并在真机上完成一次验收。

**Architecture:** 仍沿用 Phase 1 的 Rust 核心 + Vue MVVM；本次新增的跨进程能力只有两处——通知 tap 的 `reminder:open` 事件与托盘菜单的导航事件。

**Tech Stack:** Tauri 2、Vue 3 + TS、Vite+、SQLite（rusqlite）、tauri-plugin-notification / tray / global-shortcut。

**Spec:** `docs/superpowers/specs/2026-10-19-ordo-design.md`、`docs/superpowers/specs/2026-10-20-ordo-architecture.md`

## Global Constraints

- 平台 Windows；分支从 `main`（`f263a4e`）切出，命名 `feat/phase1-1`。
- 每个任务收尾：`cargo test`、`vp test run`、`vp check` 全绿，提交一次。
- 不新增依赖（除非任务显式写明）。
- 所有跨进程调用仍只经 `src/model/ipc.ts`；View 不碰 IPC。
- 通知、托盘、快捷键属于"只能真机验证"的部分：对应任务的最后一步是手工核对，结果写进 README 的验收清单。

## Review Focus

1. **通知 id 映射**：同一任务重复提醒、应用重启、id 冲突时，点通知不能打开错的或无事发生。—— Task 1。
2. **patch 语义**：`null`（清空）与"字段未提供"（保持）不能混，否则一次保存会误清 AI 刚填的字段。—— Task 2。
3. **数据库恢复**：恢复流程绝不能覆盖掉唯一一份好数据；坏文件必须先改名保留。—— Task 6。
4. **CSP 拆分**：生产收紧后，开发模式的 HMR 不能断。—— Task 5。
5. **过一遍里的浮层**：E 打开任务浮层后，Esc、回车、J/K 不能同时被两层面板处理。—— Task 3。

```rust
#[test]
fn recovers_from_latest_backup_after_corruption() {
    let dir = tempdir();
    let db = dir.join("ordo.db");
    { let c = db::open(&db).unwrap(); capture(&c, "留住的", NOW, "t1"); }
    std::fs::create_dir_all(dir.join("backups")).unwrap();
    std::fs::copy(&db, dir.join("backups/ordo-2026-10-20.db")).unwrap();
    std::fs::write(&db, b"not a database").unwrap();

    let c = db::open_with_recovery(&db, &dir.join("backups")).unwrap();
    let n: i64 = c.query_row("SELECT COUNT(*) FROM tasks", [], |r| r.get(0)).unwrap();
    assert_eq!(n, 1);
    let corrupt = std::fs::read_dir(&dir).unwrap().filter(|e| e.as_ref().unwrap().file_name().to_string_lossy().contains("corrupt")).count();
    assert_eq!(corrupt, 1);
}

#[test]
fn without_backup_keeps_corrupt_file_and_errors() { /* 返回 Err，原文件仍在，且有 .corrupt 副本 */ }
```

- [ ] **Step 2：跑测试，确认失败**
      Run: `cd src-tauri && cargo test recovery`

- [ ] **Step 3：实现**
