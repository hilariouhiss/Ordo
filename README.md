# ordo

个人任务账本：一句话捕获、每周过一遍、按专业看项目进度、延期有据可查、归档可恢复、到点会提醒。桌面应用（Tauri 2 + Vue 3），数据只在本机。

## 跑起来

```bash
vp install
pnpm tauri dev        # 桌面应用（含 Rust）
vp dev                # 只跑前端（浏览器里，无 IPC）
```

## 检查

```bash
vp check              # 格式 + lint + 类型
vp test run           # ViewModel 测试
cd src-tauri && cargo test
```

## 打包

```bash
pnpm tauri build
```

## 几个约定

- 数据在 `%APPDATA%/com.ordo.taskbook/ordo.db`，每天自动备份到 `backups/`，可手动导出 JSON；旧版 `com.ordo.app` 的数据首次启动会复制过来，旧目录保留。
- 提醒的点击只有提示条还在屏幕上时才会交给 ordo（Windows 的限制，插件文档写明了）。收进通知中心之后再点，系统不会告诉 ordo 是哪一条，只能把主窗口叫出来——这不是 bug，验收清单里按实际记。
- 数据库文件坏了不会静默重建：先把坏文件连同它的 `-wal` 存成 `ordo.db.corrupt-<时间戳>`，再从 `backups/` 里从新到旧挑第一份能打开的恢复，并弹一条通知说明用的是哪一份；没有能用的备份就写 `startup-error.txt` 后报错，什么都不删。只有文件确实损坏才走这条路，别的错误原样报出来，不会拿旧数据顶替。
- 默认语言：没在设置里手动选过时，按 Windows 系统 UI 语言（中文→中文，其他→英文）；手动选择后固定。
- 全局快捷键默认 `Ctrl+Alt+O`，呼出迷你窗口；在设置里可改。
- 桌面小窗从托盘或主窗口右上角开关；贴边自动收起，位置、层级和开关存在数据库 `settings` 的 `desk.*` 键。小窗内的开始/挂起/完成按钮由设置 → 通用的「小窗内变更任务状态」控制（`desk.controls`，默认开启），小窗挂起不填日期和原因。
- 捕获条支持 `#项目 @负责人 !高/中/低 ^周五 ~2天` 的符号；输入框下会回显这五项，点开可改。
- AI 补字段走 DeepSeek（OpenAI 兼容），key 存在 Windows 凭据管理器；不填 key 就不联网。
- Windows 安装器：setup.exe 和卸载器图标用 `src-tauri/icons/icon.ico`；NSIS 的页眉、侧栏图在 `src-tauri/installer/`，安装语言固定简体中文。MSI 仍用 WiX 默认英文界面。
- 设计文档：`docs/superpowers/specs/`，实现计划：`docs/superpowers/plans/`。
