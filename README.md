# Ordo

个人任务账本：一句话捕获、每周过一遍、按专业看项目进度、延期有据可查、归档可恢复、到点会提醒。桌面应用（Tauri 2 + Vue 3），数据只在本机。

## 跑起来

```bash
vp install
pnpm tauri dev        # 桌面应用（含 Rust）
vp dev                # 只跑前端（浏览器里，无 IPC）
```

## 检查

```bash
vp check              # 格式 + lint + 类型
vp test run           # ViewModel 测试
cd src-tauri && cargo test
```

## 打包

```bash
pnpm tauri build
```

## 几个约定

- 数据在 `%APPDATA%/com.ordo.taskbook/ordo.db`，每天自动备份到 `backups/`，可手动导出 JSON；旧版 `com.ordo.app` 的数据首次启动会复制过来，旧目录保留。
- 提醒的点击只有提示条还在屏幕上时才会交给 Ordo（Windows 的限制，插件文档写明了）。收进通知中心之后再点，系统不会告诉 Ordo 是哪一条，只能把主窗口叫出来——这不是 bug，验收清单里按实际记。
- 数据库文件坏了不会静默重建：先把坏文件连同它的 `-wal` 存成 `ordo.db.corrupt-<时间戳>`，再从 `backups/` 里从新到旧挑第一份能打开的恢复，并弹一条通知说明用的是哪一份；没有能用的备份就写 `startup-error.txt` 后报错，什么都不删。整份文件不见了而备份还在，也按同样方式恢复——否则空账本当天就会把旧备份清掉。只有文件确实损坏或丢失才走这条路，别的错误原样报出来，不会拿旧数据顶替。升级旧库前那份 `pre-migration-v<n>.db` 写不出来时，升级不跑。
- 每天那份备份先写到临时名，写完才改成正式名；当天那份如果残缺，下次 tick 会重写而不是当成已完成。
- 默认语言：没在设置里手动选过时，按 Windows 系统 UI 语言（中文→中文，其他→英文）；手动选择后固定。
- 全局快捷键：迷你窗口 `Ctrl+Alt+O`（呼出/收起捕获条）、桌面小窗 `Ctrl+Alt+W`（置底或隐藏时叫到最前，失焦还原，仅小窗形态生效）、主窗口 `Ctrl+Alt+M`（任意形态下回到完整主窗口）；都在设置 → 通用里改。
- 应用内快捷键：主窗口或小窗里 `Ctrl+N` 新建任务、`Ctrl+Shift+N` 新建项目，弹窗复用捕获语法；`Ctrl+K` 打开全局搜索，`Ctrl+Z` 撤销最近一次可逆操作（输入框内不接管，浮层打开时不触发）；只在应用窗口聚焦时生效，迷你捕获窗口和系统全局不受影响。
- 保存的任务视图存在 `settings` 的 `tasks.saved_views`（JSON，最多 20 个），与筛选一起随导出和备份走；全局搜索只匹配任务标题和活跃项目名，不搜备注、子任务和标签。
- 归档页的归档任务 / 取消 / 已完成三个列表各只显示最近 1000 条，避免多年累积后一次加载全部；搜索仍先在全表标题里匹配，再取最近 1000 条。
- 桌面小窗是主窗口的一个形态：主窗口右上角按钮或托盘开关，两种形态之间界面随窗口同步缩放、移动并交叉淡入淡出；默认落点是主屏右上角，贴边自动收起，位置、层级和开关存在数据库 `settings` 的 `desk.*` 键，小窗右上角按钮回到主窗口。小窗内的开始/挂起/完成按钮由设置 → 通用的「小窗内变更任务状态」控制（`desk.controls`，默认开启），小窗挂起不填日期和原因。
- 捕获条支持 `#项目 @负责人 !高/中/低 ~预计耗时` 的符号；输入框下会回显这四项和按耗时自动算出的预计完成，点开可改前四项。`#名字` 匹配不到已有项目时保存后自动建项目（同名复用）；`^日期` 记号已移除；捕获条里的预计完成仍是只读预览，任务浮层里可以手改。
- AI 补字段走 DeepSeek（OpenAI 兼容），只补项目/分类/负责人/标签，不猜日期；任务在补字段期间被手动改过就放弃本次补齐；key 存在 Windows 凭据管理器，不填 key 就不联网。
- Windows 安装器：setup.exe 和卸载器图标用 `src-tauri/icons/icon.ico`；NSIS 跳过欢迎页，首屏直接是用户选择页（当前用户/所有用户），完成页在 `src-tauri/installer/pages.nsh` 里改成无侧栏整页布局，页眉不显示图标；安装语言固定简体中文。MSI 仍用 WiX 默认英文界面。
- 设计文档：`docs/superpowers/specs/`，实现计划：`docs/superpowers/plans/`。
